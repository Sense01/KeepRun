# KeepRun

Aplicação web gratuita e open source para registar e analisar atividades desportivas (corrida, bicicleta, caminhada).

## Funcionalidades atuais (v0.1)
- Importar ficheiros GPX
- Gravar atividades com GPS (funciona no telemóvel, via HTTPS)
- Mapa da rota (OpenStreetMap), distância, tempo, ritmo, subida
- Gráfico de altimetria e parciais por km
- Estatísticas semanais e recordes pessoais
- Exportar GPX
- Login com Google e amigos (opcional, ver SETUP.md)
- Treinos personalizados (sugestões semanais, 43 desportos), modo guiado com avisos de áudio e rotas sugeridas
- Os dados ficam guardados no navegador (localStorage)

## Como usar
Abrir `index.html` ou publicar no GitHub Pages (Settings > Pages > branch main).
