# KeepRun

Aplicação web gratuita e open source para registar e analisar atividades desportivas.

## Funcionalidades (v0.2)
- Importar e exportar GPX (com tipo de atividade); gravar com GPS (com recuperação se a app fechar)
- Mapa da rota (OpenStreetMap), distância, tempo, ritmo, subida (com tratamento de altitudes em falta), parciais por km
- Treinos personalizados (sugestões semanais, 43 desportos), modo guiado com sons e guardar atividade com esforço e visibilidade
- Estatísticas, desafios, conquistas e sequência semanal
- Contas (Google ou email) e amigos, com zona de privacidade e apagar dados na nuvem (ver SETUP.md)
- Instalável como app (PWA) e funciona offline; dados em IndexedDB

## Como usar
Publicar a pasta no GitHub Pages (Settings > Pages > branch main, pasta /root).
